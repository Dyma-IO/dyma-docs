# Introduction

**Dyma** is a task-to-earn platform for Web3. Projects launch campaigns. Contributors complete quests. Verification is automatic where possible and human where it matters. Rewards settle from escrow directly to user wallets.

**Tagline:** *Do the task. Own the proof.*

## What Dyma provides

| Surface | URL | Audience |
|---------|-----|----------|
| User app | [dyma.io](https://dyma.io) | Contributors and earners |

## Core principles

- **Self-custody** — Dyma never holds campaign funds between escrow and payout.
- **Hybrid verification** — On-chain indexers, platform APIs, project REST endpoints, and manual review.
- **Privacy by default** — Contact data stays with Dyma; projects receive wallets and anonymized stats.
- **Portable credentials** — Reputation and points accumulate across campaigns and chains.

## How a quest flows

```
Connect wallet  →  Complete quest  →  Verify  →  Claim reward
```

Verification paths include on-chain indexing, social and GitHub integrations, project-owned REST APIs, and moderated review for custom submissions.
