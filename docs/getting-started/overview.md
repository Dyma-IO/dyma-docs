# Overview

Dyma serves three primary audiences. Pick the path that matches your role.

## Contributors (earners)

Use [dyma.io](https://dyma.io) to discover campaigns, connect a wallet, complete quests, and claim rewards.

1. Connect a Cosmos-compatible wallet.
2. Browse active campaigns on the landing page or discover tab.
3. Complete quest instructions and submit proof when required.
4. Wait for verification (seconds for on-chain tasks, up to 24h for manual review).
5. Claim rewards to your wallet when eligible.

## Project owners (Studio)

Use [studio.dyma.io](https://studio.dyma.io) to create projects, fund campaigns, and define quests.

1. Apply for or receive Studio access.
2. Create a **Project** profile (name, branding, category).
3. Add a **Campaign** with schedule, reward pool, and eligibility rules.
4. Add **Quests** from the global task type catalog or custom manual tasks.
5. Monitor submissions, analytics, and moderator queues.

See [For projects](./for-projects) for the content hierarchy and verification options.

## Developers

Contribute to open source repos, integrate with the API, or build custom verification endpoints.

1. Browse repositories on [GitHub](https://github.com/Dyma-IO).
2. Read [Contributing](../developers/contributing) before opening pull requests.
3. Use [Discussions](https://github.com/orgs/Dyma-IO/discussions) for questions that are not repo-specific bugs.
