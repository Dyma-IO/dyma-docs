# Contributing to dyma-docs

Documentation changes are welcome via pull request.

1. Fork and branch from `main`.
2. Edit pages under `docs/`.
3. Run `npm run build` locally to verify links.
4. Open a PR with a short summary of what you changed.

For broader Dyma contribution guidelines, see the [Contributing doc](https://dyma-io.github.io/dyma-docs/docs/developers/contributing) and the org-wide [CONTRIBUTING.md](https://github.com/Dyma-IO/.github/blob/main/CONTRIBUTING.md).

Security: report vulnerabilities to **dymaweb3@gmail.com** — do not open public issues.
